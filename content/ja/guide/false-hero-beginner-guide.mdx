## 基本システム：タイムブロック、ロケーション、ルーティン管理

ゲーム内の1日を最大限に活用するには、時間を最も貴重なリソースとして扱う必要があります。行動しても時間が経過しない自由度の高いアドベンチャー作品とは異なり、『False Hero』では主要なロケーションへの移動やキャラクターとの会話を行うたびにゲーム内時計が進みます。

各エリアがどの時間帯に対応しているかを把握することで、無駄な行動を減らすことができます。自宅はベース拠点として機能し、ルーシー（Lucy）が滞在しているほか、深夜のマイルストーンイベント用の一室としても使われます。一方、職場、ダウンタウンのカフェ、他の住宅などの商業・居住エリアは特定の時間帯のみ利用可能です。

| 時間帯 | 主に利用可能な拠点 | 優先度の高い行動 |
| :--- | :--- | :--- |
| **早朝** | 自宅、職場、双子の家 | 収入を得るための勤務、リビングでの軽いストレッチ |
| **朝** | 自宅（バスルーム / キッチン） | 家の中での会話、日課の確認 |
| **昼** | 職場、カフェ、メラニーの家、リビング | ジェーンのストーリーイベント、双子との交流、メラニーの部屋への訪問 |
| **午後** | ダウンタウンのカフェ、商業地区 | プレゼントの購入、カフェでの事前会話 |
| **夕方** | 自宅、双子の家、メラニーのリビング | 一緒に夕食をとる、日常会話、交流イベントの進行 |
| **夜** | リビング（ゲーム機）、双子の家（バスルーム） | ゲームセッション、夜のリラックスイベント |
| **深夜** | 自宅寝室、双子の家のリビング | 深夜のゲームイベント、メディア視聴、1日の終了 |

本**False Hero 初心者ガイド**で推奨する基本戦略は、「再現性の高い日課リズム」を確立することです。第1週目からすべてのキャラクターを均等に進めようとすると、注意が分散して効率が落ちてしまいます。まずは早朝の勤務で資金を確保し、昼は影響の大きい重要なソーシャルイベントに充て、夕方以降は同居キャラクターとの交流に専念するのがベストです。

## 序盤の経済基盤：キャリアアップとジェーンのルート

経済的な余裕は、プレゼントの購入、娯楽活動への出費、移動範囲の拡大スピードに直結します。序盤のチャプターにおける主な収入源は、会社へ出勤することです。

ジェーン（Jane）はプレイヤーの上司であると同時に、メインヒロインの一人でもあります。コミュニティの攻略情報でも指摘されている通り、キャリアの進行とジェーンのシナリオは密接に結びついています。彼女との信頼関係を深めると昼のオフィス訪問が解放され、日中の行動の選択肢が大きく広がります。

```
[早朝に出勤] 
       │
       ▼
[資金を蓄積＆業務実績を積む] 
       │
       ▼
[昼のオフィスへの出入りを解放] 
       │
       ▼
[ジェーンのセラピーを開始＆セッション1〜7を進行]
```

まずは、毎日の「早朝」スロットを出勤に充てて資金を稼ぎましょう。上司から昼のオフィス訪問の許可を得た後は、稼ぎとジェーンとの交流へバランスよく時間を配分できるようになります。

| 段階 / トリガー | 場所＆時間帯 | 必要なアクション | 期待される結果 |
| :--- | :--- | :--- | :--- |
| **仕事の開始** | 職場（早朝） | 継続して出勤する | 日給の獲得と仕事の実績を蓄積 |
| **昼の昇格** | 職場（昼） | デスクにいるジェーンと話す | 昼休みの職場探索が解放 |
| **セラピー編（1〜3）** | ジェーンのオフィス（昼） | 初期のセラピー評価を完了する | 従順度の上昇と服装変更の解放 |
| **セラピー編（4〜7）** | ジェーンのオフィス（昼） | 行動改善セッションを進める | 発展的なトレーニング会話の解放 |
| **行動トレーニング** | ジェーンのオフィス（昼） | 前向きな選択肢を選ぶ | 個別ストーリーラインのマイルストーンを全解放 |

ジェーンのオフィス内での選択肢には十分注意してください。選択肢が表示された際は、建設的かつ関係を前進させる回答を選ぶことで、進行の停滞を防ぐことができます。イベントが発生しない場合は、早朝の出勤回数の条件を満たしているかを再確認してください。

## 家事・同居生活：ルーシーの同居ストーリーライン

ルーシーのストーリーラインはほぼ自宅内で完結するため、初心者にとって最もスケジュールを最適化しやすいルートです。彼女のイベントは主に朝のルーティン、リビングでのリハーサル、深夜のゲームセッションで構成されているため、会社の収入を犠牲にすることなく進行できます。

ルーシーのルートを攻略する鍵は「順番通りのフラグ回収」です。朝のバスルームイベントや深夜の部屋訪問を一度でも飛ばしてしまうと、昼のリハーサルイベントが進まなくなってしまうという報告が多数寄せられています。

| イベント段階 | 時間帯 | 場所 | アクション / トリガー |
| :--- | :--- | :--- | :--- |
| **ゲーム導入** | 夜 | リビング | Xboxのゲーム機を通じてルーシーと交流 |
| **深夜のゲーム 1/5** | 深夜 | 寝室 | 深夜のゲームセッションを開始 |
| **朝の会話** | 早朝 | キッチン | 朝食の準備中に会話をする |
| **バスルームイベント 1**| 朝 | バスルーム | 朝のルーティン中に立ち入る |
| **昼のリハーサル**| 昼 | リビング | 台本のリハーサルに参加する |
| **深夜のゲーム 2〜5** | 深夜 | 寝室 | 連夜繰り返してゲーム編を完了させる |
| **バスルームイベント 2〜6** | 朝 | バスルーム | 毎朝バスルームをチェックして進行を完遂する |

ここでは継続性が何よりも重要です。例えば、「深夜のゲーム」イベントを完了するには5回分の深夜の寝室訪問が必要であり、「バスルームイベント」は朝に計6回連続で発生します。深夜にうっかりそのまま就寝してしまうと、ルーシーの進行がまる1日分遅れることになります。日が暮れる直前には帰宅できるように夕方のスケジュールを調整しましょう。

## 街の交流スポット：双子（ケイト＆アシュリー）とカフェ巡り

双子の姉妹であるケイト（Kate）とアシュリー（Ashley）のストーリーは、自宅外の探索を伴うルートです。昼や午後の時間帯に地元のカフェへ通うことで彼女たちと出会えます。自宅内で完結するルーシーのルートとは異なり、双子の家へ招待されるには根気とお金が必要になります。

本**False Hero 初心者ガイド**の実機検証でも、カフェを1回訪れただけで即座に家に招待されると勘違いしてしまうプレイヤーが多く見られました。双子のルートを進めるには、何度も足を運んで信頼関係を築き、特定の会話チェックをクリアする必要があります。

```
[カフェを訪問（午後）] ──> [気前よくアイテムを奢る]
                                   │
                                   ▼
[カフェを訪問（昼）] ────────> [コーヒーを注文して様子を伺う]
                                   │
                                   ▼
[コーヒー注文を繰り返す] ───> [双子の家を解放]
```

### 双子の家の解放手順

1. **午後にカフェを訪れる**：ケイトとアシュリーに気前よくアイテムをご馳走し、第一印象をアップさせます。
2. **昼に再訪する**：コーヒーを注文し、二人を観察するオプションを選択します。
3. **昼のルーティンを繰り返す**：数日間にわたりコーヒーを注文し、二人の会話を見守ります。選択肢が表示されたら、関係性を前進させる選択肢を一貫して選びましょう。
4. **自宅への招待**：親密度が一定値に達すると、双子の自宅へ招待されます。

| 時間帯 | 双子の家の中の場所 | 行動 / ストーリーフラグ |
| :--- | :--- | :--- |
| **早朝** | リビング | 脚のエクササイズルーティン（パート1＆2） |
| **昼** | メインエリア / キッチン | カジュアルな会話・様子見 |
| **夕方** | 寝室 / キッチン | 交流イベントの後、一緒に夕食をとる |
| **夜** | バスルーム＆寝室 | 共同バスルームイベント（1〜4）、双子とお泊まり |
| **深夜** | リビング | ソファで一緒にアニメ鑑賞 |

双子ルートの大きなメリットは「進行度の共有」です。ケイトのイベントを進めることで、自動的にアシュリーの対応するイベントも解放されます。双子の家が解放された後は、資金に余裕があれば早朝の勤務の代わりにリビングでのエクササイズに参加するのも有効な選択肢です。

## 複雑な分岐：メラニーとティファニーの連動ルート

この連動ルートを開始するには、まず昼にメラニーの家を訪れます。彼女の個室を解放するには、事前に自宅前へ2回訪問する必要があります。部屋へ自由に入れるようになると、新しい交流イベントがスケジュールに追加されます。

| **部屋の解放** | 昼 | メラニーの寝室 | 部屋に入り、お手伝い会話を開始 |

## 上級者向け進行テクニックとよくある失敗例

ノベルシミュレーションゲームで毎日のスケジュールを完璧に管理するには、先を見越した行動が不可欠です。よくある失敗を避けるため、以下の実践的なテクニックを活用してください。

* **セーブスロットを複数保持する**：ゲーム内の週の初めには、必ずローテーション用セーブデータを残しておきましょう。一度きりの朝のフラグを逃してしまった場合、最初からやり直すよりも直近の週頭からロードする方が遥かに簡単です。
* **第1週は資金繰りを最優先にする**：すぐにキャラクターの個別イベントを追いかけたくなるかもしれませんが、所持金が尽きるとカフェでの購入ができなくなります。最初の数日間の早朝は、しっかりと出勤して稼ぎましょう。
* **キャラクターのスケジュールをメモしておく**：ルーシー、ジェーン、双子には厳格な発生条件があるため、予定表をメモしておくのが効果的です。例：早朝（仕事） $\rightarrow$ 昼（ジェーン/メラニー） $\rightarrow$ 午後（カフェ） $\rightarrow$ 夕方（夕食） $\rightarrow$ 深夜（寝室ゲーム）。
* **些細なセリフのヒントを見逃さない**：キャラクターは日常会話の中で次のイベントのヒントを口にすることがよくあります。リハーサルや運動の話題が出た場合は、翌日の該当する時間帯にその部屋をチェックしてみましょう。
* **コミュニティ情報を活用する**：ノベルゲーム特有のシステムや技術的なトラブルシューティングについては、[Steam Community](https://steamcommunity.com) などのプラットフォームで一般的な議論を参照すると、システム設定やパフォーマンス調整、エンジンの癖などを把握するのに役立ちます。

## 効率を最大化するデイリースケジュール例

スケジュールの衝突を起こさずに複数のキャラクタールートを並行して進めたい場合は、以下のバランス型デイリールーティンに従ってみてください。

```
[早朝]   ──> 出勤する（または双子の家で脚のエクササイズ）
  │
[朝]     ──> 自宅のバスルーム / キッチンでルーシーのイベントを確認
  │
[昼]     ──> 交互に進行：ジェーンのオフィス または メラニーの寝室
  │
[午後]   ──> ダウンタウンのカフェで双子の進行 / コーヒー注文
  │
[夕方]   ──> メラニーのリビング または 双子の家で夕食
  │
[夜]     ──> 自宅リビングでルーシーとXbox または 双子の家のバスルーム
  │
[深夜]   ──> 自宅寝室でルーシーとゲーム または 双子とアニメ鑑賞
```

このバランス型サイクルを採用することで、誰か一人の進行が止まるのを防ぎつつ、安定した収入を維持し、街中の新しいエリアを順調に解放していくことができます。

## よくある質問（FAQ）

### このFalse Hero初心者ガイドで最初に集中すべきことは何ですか？
最初の数日間は、早朝スロットでの出勤を最優先してください。序盤に資金を稼いでおくことで、双子の家を解放するために不可欠なカフェ通いやプレゼント代を賄えるようになります。収入基盤が整ったら、昼の時間をジェーンのオフィスのセラピーとメラニーの自宅訪問に交互に割り当て始めましょう。

### ティファニーと話せない・新しいシーンが発生しないのはなぜですか？
ティファニーのストーリーラインは、メラニーの進行度に完全に依存しています。ティファニーが無反応だったりイベントが発生しなかったりする場合は、昼にメラニーの寝室へ戻ってください。メラニーの様子を確認し、ティファニーに関するアドバイス（フェーズ1〜4）を完了させることで、初めてティファニー単独の夕方や夜のシーンが解放されます。

### ドアに鍵がかかっていてルーシーのバスルームイベントが発生しません。
ルーシーのバスルームシーンを見るには、それ以前の前提ストーリーマイルストーンを完了している必要があります。深夜に寝室で一緒にゲームをプレイし、早朝にキッチンで会話を済ませているか確認してください。ルーシーの6つのバスルームイベントは順番に解放されるため、手前のフラグを見落としていると次のイベントは発生しません。

### このFalse Hero初心者ガイドに沿って進めれば、1周で全キャラクターを攻略できますか？
はい、可能です。本作のスケジュールシステムは、取り返しのつかないルート固定を起こすことなく、1日の中の異なる時間帯を使って複数のストーリーラインを両立できるように設計されています。早朝を仕事、昼をジェーンやメラニー、午後をカフェ、夜をルーシーや双子に充てることで、1回のプレイですべてのキャラクターのストーリーラインを余すところなく楽しむことができます。
