## ゲームパッド操作体系（XboxおよびPlayStation）

開発者は専用コントローラーでのプレイを強く推奨しています。戦闘リズムは、滑らかなアナログスティック操作とショルダーボタンでの攻撃を軸に設計されており、クラシックなアクションRPGを思わせる手触りとなっています。

標準的なコントローラー配置で **false hero controls** に慣れておけば、カメラ操作を損なうことなく、防御トリガーと攻撃トリガーに自然と指を添えることができます。最新のXboxワイヤレスコントローラーおよびPlayStationのDualShock／DualSenseコントローラーの双方がネイティブサポートされています。

## PCキーボード＆マウスのキー配置

ゲームパッドは滑らかな方向入力を可能にしますが、精密なエイムや素早いカメラ追従のためにマウスを好むプレイヤーも少なくありません。標準的なWASDレイアウトに慣れれば、キーボード＆マウス（KBM）によるデフォルトの **false hero controls** でも十分に快適なプレイが可能です。

マウスでカメラの向きと通常攻撃を担い、左手で回避、ジャンプ、奪った戦闘技術の発動を連携させます。

### PCキーボード＆マウスのデフォルトキー配置

| アクションカテゴリー | ゲーム内アクション | デフォルトキー / マウス入力 | 推奨の代替設定 |
| :--- | :--- | :--- | :--- |
| **移動** | 前進 / 後退 | `W` / `S` | デフォルト |
| **移動** | 左平行移動 / 右平行移動 | `A` / `D` | デフォルト |
| **移動** | ダッシュ / 長距離ダッシュ | `Left Shift`（長押し） | `Left Shift` または マウスサイドボタン |
| **移動** | 回避 / ローリング | `Spacebar`（短押し）または `Left Alt` | `Spacebar`（最も応答性が高い） |
| **戦闘** | 通常攻撃 | `マウス左クリック（LMB）` | デフォルト |
| **戦闘** | 強攻撃 / 特殊攻撃 | `マウス右クリック（RMB）` | デフォルト |
| **戦闘** | 仮面術 / 技の奪取 | `Q` または `E` | `マウスボタン4`（サイドボタン） |
| **戦闘** | 神聖ガード / 弾き | `F` | `マウスホイールクリック` または `RMB` |
| **ターゲティング** | カメラロックオン | `マウスホイールクリック` | `Tab` または `マウスボタン5` |

## 仮面システムと戦闘技術の入力フロー

本作の最大の特徴は、倒したモンスターやボスから戦闘技術を吸収できるシステムです。**false hero controls** を自在に操ることで、これらの技を奪い、標準的な剣撃コンボの中にシームレスに組み込むことが可能になります。

煩雑なメニュー画面で武器を入れ替える従来の装備型ソウルライクとは異なり、仮面が瞬時の触媒として機能します。固有の技を持つ敵を撃破した際、インタラクトまたは吸収入力を押すことで、その技が即座にアクティブアーツバーへと登録されます。

### 戦闘入力とアビリティ発動の仕組み

| 戦闘フェーズ | コントローラーの入力手順 | PC（KBM）の入力手順 | 発動するゲーム内効果 |
| :--- | :--- | :--- | :--- |
| **1. コンボ始動** | `RB` -> `RB` | `LMB` -> `LMB` | 敵をよろめかせる標準的な2段弱斬撃 |
| **2. 技の連携** | `RB` -> `Y` | `LMB` -> `Q` | 弱攻撃を即座にキャンセルして奪った技へ派生 |
| **3. 神聖モディファイア** | `LT` + `RT` | `F` + `RMB` | 神の力を消費して強力な神聖強打を放つ |
| **4. 素早い離脱** | `B`（左スティック後方入力） | `Spacebar` + `S` | 無敵時間を利用した素早いバックステップ |
| **5. アビリティ吸収** | 死体の近くで `X長押し` | 死体の近くで `E長押し` | 撃破した敵の技を仮面へと転写・保存 |

本作の戦闘はレベル上げよりもスキルの習熟と連携を重視しているため、入力先行入力（バッファ）の判定がシビアに設定されています。ボタンを連打すると意図しないアクションがキューに入り、敵の反撃に対して無防備になってしまいます。前のモーションが視覚的なインパクトを迎える瞬間に合わせ、コマンドを1つずつ正確に入力してください。

## 高度な立ち回り、回避、そしてコンボ連携

ボス戦を制するには、硬直時間（リカバリーフレーム）とヒットリアクションのタイミングを深く理解する必要があります。激戦の中で **false hero controls** の精度を高めるということは、攻撃をローリングでくぐり抜けるべき瞬間と、位置取り（間合い管理）でかわすべき瞬間を見極めることを意味します。

コミュニティ体験版の検証により、直立バックステップ、方向入力ローリング、神の力をまとったダッシュのどれを行うかによって、回避後の硬直時間が大きく異なることが判明しています。

### 回避アクションの性能とバッファウィンドウ

| 移動テクニック | 入力方法 | 無敵時間（目安） | スタミナ / フロー消費 | 最適な使用シチュエーション |
| :--- | :--- | :--- | :--- | :--- |
| **ニュートラルバックステップ** | スティックを倒さずに `B` / `Space` | 短い（約0.2秒） | 極小 | 敵との間合いを保ちつつ横薙ぎを回避する時 |
| **方向指定ローリング** | 方向入力 + `B` / `Space` | 中程度（約0.35秒） | 中程度 | ボスの薙ぎ払い型飛び道具をくぐり抜ける時 |
| **ゴッドダッシュ** | `LT` + `B` / `Shift` + `Space` | 長い（約0.5秒） | 高（パワー消費） | 広範囲のAoE（範囲攻撃）叩きつけから脱出する時 |
| **スプリントスライド** | `ダッシュ中` に `B` / `Space` | 極小（位置調整用） | 低 | 遠距離の魔術師系エネミーへ急速接近する時 |

### コンボ成功の秘訣

1. **過度な先行入力を避ける：** 入力バッファは約0.5秒先までコマンドを記録します。敵がカウンターの予備動作に入っている最中に強攻撃を先行入力してしまうと、キャンセルすることはできません。
2. **弱攻撃の合間に奪った技を織り交ぜる：** 弱攻撃（`RB` / `LMB`）はモーション後の硬直が最も短いです。発生の遅い強力な奪取技を割り込まれずに放つための起点として活用しましょう。
3. **ロックオンを臨機応変に解除する：** 巨大な機械獣や蜘蛛型の怪物と戦う際は、あえてロックオンを外すことで方向指定ローリングの自由度が高まり、敵の死角へと素早く回り込むことができます。

## 推奨設定とキャリブレーション

オプションメニューで **false hero controls** を適切に設定しておくことで、操作レスポンスが向上し、アクロバティックなボス戦における不快なカメラの引っかかりを防ぐことができます。

### ゲームプレイおよびコントローラーの最適設定

| 設定項目 | デフォルト値 | 推奨値 | 設定理由 |
| :--- | :--- | :--- | :--- |
| **コントローラー デッドゾーン** | 15% | 5% – 8% | スティックの遊びを減らし、回避の反応速度を高速化 |
| **カメラ感度（X軸・水平）** | 50% | 65% – 70% | 背後へ素早く回り込む敵を瞬時に視界に捉えるため |
| **カメラ感度（Y軸・垂直）** | 50% | 55% – 60% | 飛行する敵や巨大な敵をスムーズに上下追従するため |
| **撃破時オートターゲット** | オフ | オン | 敵を倒した際、最も近い次の敵へ自動でロックを移行 |
| **カメラの揺れ / ボブ** | 100% | 20% – 40% | 強力な打撃攻撃の際にも画面の視認性を安定させるため |
| **振動の強さ** | 100% | 50% – 70% | エイムの邪魔をせず、的確なヒットフィードバックを得るため |

経年劣化したコントローラーでスティックのドリフト現象が発生する場合は、キャラクターの勝手な移動が収まるまでデッドゾーンを2%ずつ引き上げてください。高DPIゲーミングマウスを使用するPCプレイヤーは、ゲーム内マウス感度を下げることで、素早くマウスを振った際の極端なカメラ回転を防ぐことができます。

## よくある質問（FAQ）

### コントローラーでのFalse Heroのデフォルト操作はどうなっていますか？
Xboxコントローラーの場合、左スティックで移動、右スティックでカメラ操作、`RB` で弱攻撃、`RT` で強攻撃、`B` で回避、`A` でジャンプを行います。敵の技を奪って発動する仮面アビリティは `Y`、ガードは `LB`、神の力の構えは `LT` に割り当てられています。PlayStationコントローラーも同様に、弱攻撃が `R1`、強攻撃が `R2`、回避が `○`、仮面アビリティが `△` となります。

### False Heroの操作設定は自由にカスタマイズ（リマップ）できますか？
はい。ゲーム内の設定メニューからキーボードの割り当てを自由に変更できます。コントローラーを使用している場合は、ゲーム内オプションでボタン配置を変更できるほか、Steam入力を活用してカスタムボタンマッピング、デッドゾーンの調整、エリートコントローラーの背面パドル設定などを行うことが可能です。

### False Heroはコントローラーとキーボード＆マウスのどちらでプレイするのがおすすめですか？
False Heroの開発者は、コントローラーでのプレイを明確に推奨しています。全方位への移動や、ショルダーボタン攻撃と前面ボタン回避の滑らかな連携は、ゲームパッドに最適化されています。ただし、キーボード＆マウスでのプレイも完全サポートされており、仮面術などの重要な戦闘機能をマウスのサイドボタンにリマップすれば快適にプレイできます。

### 敵から奪った攻撃はどのボタンで発動しますか？
戦闘技術を持つ敵を倒した後、近づいてインタラクトボタン（Xboxは `X`、PlayStationは `□`、PCは `E`）を長押しすると、そのスキルを仮面に吸収できます。装備後は、戦闘中に仮面術ボタン（`Y`、`△`、または `Q` / `マウスボタン4`）を押すことで発動でき、通常の武器攻撃の直後から流れるようにコンボへ繋ぐことが可能です。
