### キーボードプレイヤー向けキー配置変更の戦略

サブ攻撃やアクティブな戦技をマウスのサイドボタン（マウス4、マウス5）に割り当てることで、WASDキーによる全方向への移動を維持しつつ、無理な指の動きをなくせます。プレイヤーの実体験によると、斜め移動（`W` + `A`や`W` + `D`）を行っている最中に`Q`や`E`を押そうとすると、激しい多段階ボス戦において回避のリズムが狂いやすくなります。

さらに、広範囲攻撃（AoE）の危険区域からスプリントで逃げようとした際に誤ってロールが暴発するのを防ぐため、メインの回避/ステップを`スペースバー`のみに割り当て、タップによるスプリント機能を分離することを検討してください。

### コントローラーの微調整とデッドゾーン管理

Steam入力経由で『**False Hero PC**』を起動する際、最高の応答性を得るにはSteamオーバーレイからコントローラーのデッドゾーンを調整しましょう。スティックの内部デッドゾーンをおよそ5%〜8%に設定すると、不意のスティックドリフトを防ぎつつ、ボスの連続攻撃を回避する際の一瞬の入力反応速度を高められます。

コミュニティの報告では、回避/ロールを背面パドル（Steam DeckのL4/R4やXbox Eliteコントローラーのパドルなど）に割り当てることが推奨されています。これにより、右親指を右アナログスティックから離すことなく、スプリント、回避、カメラ視点変更を同時に行うことができます。

## 戦技と入力メカニクス：コンボのタイミング

穢れた領域における戦闘は、極めてハイテンポなサイクルが中心となります。敵の攻撃パターンを把握し、撃破して学者としての仮面でその固有アクションを奪い、攻撃ルーチンへ即座に組み込むという流れです。

素早く動くボスに対抗するには、『**False Hero PC**』の先行入力（入力バッファ）とキャンセルウィンドウの仕組みを理解することが不可欠です。本作の戦闘エンジンは無秩序なボタン連打を許容せず、意図的なアクションキュー方式を採用しています。

以下の表は、代表的な入力連携がゲームエンジン内でどのように処理されるかを示したものです。

| アクションシーケンス | 入力受付ウィンドウ | エンジン挙動 / バッファ規則 | 推奨される戦略的活用 |
| :--- | :--- | :--- | :--- |
| **弱攻撃 > 奪った戦技** | 攻撃スイングモーション中 | 最短のリカバリーフレームで発動するよう戦技をバッファ | ボスの反撃前に繰り出す素早いバーストダメージ |
| **強攻撃 > 回避キャンセル** | 溜めモーションの頂点前 | 攻撃動作を中断し、完全な無敵フレーム付きロールへ移行 | ボスの大振りを安全に誘い出す（フェイント） |
| **回避 > カウンターストライク** | 無敵フレーム終了直後 | 怯みボーナスを持つ専用の突進突き攻撃を発動 | ボスの攻撃空振り後に一気に間合いを詰める |
| **連続戦技チェーン** | 戦技1のヒットストップ中に戦技2を入力 | ニュートラル状態を経由せず2つの敵スキルを隙なく連続発動 | 敵が体勢を崩した際に体幹を一気に削り切る |
| **神の権能バースト** | ニュートラル姿勢または被弾硬直中 | 無敵の発生フレームで通常の被弾硬直を上書き | 緊急時の防御手段、またはボスのフェーズ撃破のトドメ |

### 先行入力とモーション硬直の管理

攻撃ボタンを素早く3回連続で叩くと、エンジンはその3回分のスイングをすべてキューに入れます。もし最初の一撃の最中に敵が致命的な振り下ろし攻撃の予備動作に入った場合、余分に予約された入力のせいで時間内に回避ロールへ移ることができなくなります。

意図したアクション1回につき1回だけ入力する、確実なキー入力を指に覚え込ませましょう。知恵の峰にそびえる王国を軽快に駆け抜けるプレイヤーと、序盤のボスで立ち往生してしまうプレイヤーを分けるのは、この精密な操作規律の習得であるとコミュニティでも頻繁に指摘されています。

詳細な設定を行う前に、お使いのPCが[False HeroのSteamストアページ](https://store.steampowered.com/app/2538870/False_Hero/)に記載されている公式推奨スペックを満たしているか、または上回っているか確認してください。

### 入力遅延を最小化するゲーム内グラフィック設定

『**False Hero PC**』のプレイにおいてクリックから画面反映までの遅延（Click-to-Photonレイテンシ）を最小限に抑えるには、グラフィックの精細さと純粋なパフォーマンスのバランスが肝心です。手作業で構築されたレトロビジュアルは動作が軽快であり、ミドルスペックの環境でも高いフレームレートを維持できます。

以下の設定表を参考に、グラフィックメニューを調整してください。

| グラフィック項目 | 推奨設定 | 入力遅延と滑らかさへの影響 |
| :--- | :--- | :--- |
| **ディスプレイモード** | 排他フルスクリーン | WindowsのDWMによる合成遅延をバイパス |
| **垂直同期（V-Sync）** | オフ（GPUコントロールパネル側でG-Sync/FreeSyncを有効化） | 従来のダブルバッファリングによる垂直同期遅延を排除 |
| **フレームレート制限** | モニターのリフレッシュレートより3 FPS低く設定（例：144 Hzなら141 FPS） | 可変リフレッシュレート範囲を常に維持 |
| **シャドウ品質** | 中 | 混戦となるボスアリーナでのCPUドローコール急増を緩和 |
| **ポストプロセス / モーションブラー**| 無効 / オフ | ボスの予備動作の視認性を向上 |
| **アンチエイリアス** | TAA または FXAA（低） | レンダリング負荷を増大させずにエッジを滑らかに維持 |

## 高度な戦闘戦術とカメラ操作

青々とした沼地、凍てつく廃墟、太古の都市といった超現実的な世界を生き延びるには、武器のモーションセットだけでなく、カメラの挙動も自在に操る必要があります。巨大なボスと戦う際、近距離でロックオンしたままだとボスの巨躯で攻撃の予備動作が見えなくなってしまうため、多くのソウルライクプレイヤーがつまずく原因となっています。

### ロックオンの柔軟な使い分け

ターゲットロックオン機能は敵を自動で画面中央に捉えてくれますが、常に固定し続けると不利に働く局面もあります。群がる小型エネミーや巨大な蜘蛛型ボスのような部位の多い敵との戦闘では、あえてノンロックで戦うことで優れた状況把握が可能になります。

- **ロックオン推奨：** 1対1の人型決闘、飛行する有翼の敵、直線的な弾道を持つ遠距離戦技を確実に命中させたい場合。
- **ノンロック（ロック解除）推奨：** 大勢の敵に囲まれた乱戦、広範囲に広がる危険な床面トラップからの離脱、広角の水平強攻撃スイングを任意の方向へ手動で振り抜きたい場合。

### 立ち回り、強靭度、リカバリーフレーム

本作は従来の装備掘りを排し、純粋なプレイヤースキルの習熟を重視しているため、適切な位置取りこそが最大の防御となります。奪った戦技を連携させる際は、各アクションの硬直時間（リカバリータイム）を見極めましょう。
- 剣を持った一般的な亡者から得られる素早い斬撃は、後隙が短いため安全なコンボの起点として重宝します。
- 一方で獣系の強烈な叩きつけは、敵の体勢を崩す絶大なスタッガーダメージを与えるものの、タイミングを誤ると手痛い反撃に晒されます。

最後の攻撃入力を終えた直後、敵の反撃に反応して即座に回避ロールを出せるよう、スタミナゲージは常に最低でも15%〜20%残しておくことを徹底してください。

## よくある質問（FAQ）

### 『False Hero PC』はキーボード＆マウスでも快適にプレイできますか？
はい。ソウルライク作品ではコントローラーが好まれる傾向にありますが、『**False Hero PC**』はキーボード＆マウス操作に完全対応しています。サブ攻撃や発動頻度の高い戦技をマウスのサイドボタンに割り当てることで、素早く精密なカメラ操作が可能となり、ゲームパッドプレイヤーと何ら遜色ないコンボ操作を行えます。

### 『False Hero PC』はSteamでコントローラーにネイティブ対応していますか？
はい、本作はXboxおよびPlayStationコントローラーにネイティブ対応しており、適切なボタンアイコンがゲーム内に表示されます。さらにSteam Deckでも「プレイ可能」評価を獲得しているため、Steam入力プロファイルやコミュニティ設定を活用して、自分の手のサイズや好みの握り方に合わせて自由にリマップできます。

### 『False Hero PC』で敵の能力を奪って発動する方法は？
主人公が身につける仮面により、撃破した敵から固有のアビリティを奪い取ることができます。敵を倒した後、その残骸にインタラクトすることで戦技を獲得できます。獲得した戦技はロードアウト枠に複数セットでき、割り当てられたスキルホットキー（キーボードなら`Q`/`R`、コントローラーなら`LB`/`LT`）を押すことで、通常の剣撃コンボに即座に織り交ぜて発動できます。

### 『False Hero PC』プレイ中の入力遅延を減らすにはどうすればよいですか？
入力遅延を最小限に抑えるには、ゲームを「排他フルスクリーン」モードで実行し、ゲーム内の垂直同期（V-Sync）をオフにした上で、グラフィックスドライバのコントロールパネル側でモニターの最大リフレッシュレートよりわずかに低いフレームレート制限を設定してください。コントローラーを使用している場合は、Steamのコントローラー設定でアナログスティックのデッドゾーンを小さくすることで、移動や回避のレスポンスが格段に向上します。
