複数の異なる武技を同時にストックしておくことが可能です。コンボの最中にこれらの武技を切り替えることで、従来の職業クラスでは到底実現できない独自のアタックシーケンスを構築できます。

### 先行入力（インプットバッファ）とコンボキャンセル猶予

戦闘の滑らかさは、入力のバッファリング（先行入力）に大きく左右されます。本作では、現在の攻撃モーションの硬直中に次の打撃を先行入力しておくことが可能です。ただし、モーションの長い大技を無闇に確定させてしまうと、手痛い隙を晒すことになります。

*   **状況に応じたキャンセル：** 発生の早い武技の予備動作中に回避（B / スペースバー）を押すとモーションがキャンセルされ、スタミナを温存しつつボスの反撃から逃れることができます。
*   **バッファのタイミング：** 強力な神の力は硬直時間が長く設定されています。相手が確実に怯んでいるか、自身のコンボ後の隙を晒しているとき以外は、強攻撃の先行入力は避けてください。
*   **スタミナ管理：** 回避は攻撃とスタミナゲージを共有しています。緊急時のバックダッシュをいつでも出せるよう、スタミナバーは常に最低でも15%残しておくよう意識しましょう。

### Steam入力プロファイルの微調整

カスタムバインドを好む場合、Steam標準のコントローラー設定機能により自由自在なカスタマイズが可能です：

1. Steamライブラリを開き、本作を選択して**コントローラー設定**アイコンをクリックします。
2. 接続しているゲームパッドモデル（Xbox、DualSense、汎用HIDなど）の**Steam入力を有効化**します。
3. バンパーやトリガーの入力しきい値を「ヘアトリガー」モードに設定し、弱攻撃の反応速度を高めます。
4. （Steam Deckユーザー向け）左トラックパッドに仮想ラジアルメニューを設定し、順番に切り替えることなく特定の神技を直接発動できるようにします。

## 高度な立ち回り、回避、ボス戦のペース配分

**false hero steam**における過酷な戦いを乗り越えるには、攻撃の連撃と慎重な防御・硬直管理を調和させることが不可欠です。本作は装備の周回よりもプレイヤーの純粋なスキル習得を重視しているため、攻撃判定（ヒットボックス）の挙動と位置取りの優位性を理解することが勝利への王道となります。

ゲーム内に登場するボスは、巨大な多脚蜘蛛からそびえ立つ天使のような存在まで、多彩なタイプが存在します。各ボスには固有の攻撃パターンが存在し、単純なローリング連打ではなく、それぞれに適した防御カウンター入力で対処する必要があります。

| 脅威タイプ | ボスの予備動作（予兆） | 誤った入力対応 | 最適な入力リアクション |
| :--- | :--- | :--- | :--- |
| **広範囲薙ぎ払い** | 武器を高く振り上げ、刀身が発光 | 後方へ一直線にローリング（追撃を被弾） | 攻撃の軌道へ向けて斜め前方へすれ違いローリング |
| **多段連続乱舞** | 武器の高速回転や低い前傾姿勢 | 単発のパニックロール（追撃に引っかかる） | 初撃をガードで防ぎ、直後に横方向へ回避 |
| **地割れ衝撃波** | ボスが宙へ跳躍し、着地時に地面が陥没 | 地表を伝う衝撃波をブロックまたはパリィ | タイミングを合わせたジャンプ（X / スペース）から空中攻撃 |

| **ガード不能掴み / 刺突** | ガード不能を示す赤いパーティクルが発光 | LB / Shift でパリィを試みる | 即座にダッシュで距離を取るか後方へ2連ドッジ |

### アリーナの空間管理とカメラアングル

**false hero steam**のキャンペーンを進める上で、周囲の空間を完全に把握し続けることは極めて重要です。多くの戦闘エリアには崩落する床や断崖絶壁が存在するため、こまめにカメラロックをリセットすることで視点移動による混乱を防ぐことができます。

*   **乱戦時はロックオンを解除：** 変異した信徒の群れと対峙する際は、カメラロックを解除（R3 / ホイールクリック）して周囲を自由に見渡し、死角から突撃してくる敵を察知します。
*   **ボスとの一騎討ちは再ロック：** 単体の強敵と戦う際はしっかりロックオンを行い、前方への突き攻撃を伴う武技が弱点へ正確に向くようにします。
*   **地形への警戒：** 被弾時の吹き飛びモーションによって奈落の底へ落下する恐れがあるため、戦いの中心は常に崖際から離れた場所に維持してください。

## よくある質問（FAQ）

### False Hero Steam版はボタンの完全リマップに対応していますか？
はい、ゲーム内のオプションメニューから直接割り当てを変更できるほか、Steam入力を活用することも可能です。Steam入力を利用すれば、カスタムボタンレイヤーの作成、アナログスティックのデッドゾーン調整、対応コントローラーの背面パドルへの複雑な操作割り当てなどが行えます。

### False Hero Steam版のPC必要動作環境はどのくらいですか？
最低動作環境として、64ビットのWindows 10環境、Intel Core i5-8400またはAMD Ryzen 5 2600プロセッサー、8GBのRAM、NVIDIA GeForce GTX 970グラフィックカードが必要です。1080pまたは1440p解像度で滑らかな60FPS以上のパフォーマンスを得るには、16GBのRAMとRTX 2060またはRadeon RX 6600の組み合わせを推奨します。

### コントローラーで強奪した敵のスキルはどうやって使用しますか？
仮面を通じて敵の武技を獲得した後、左トリガー（PlayStationではL2）、または自身が割り当てたサブアビリティキーを押すことで発動できます。装備している武技は、方向パッド（十字キー）の左または右を押すことでいつでも即座に切り替えられます。

### 特別な設定をしなくてもSteam DeckでFalse Heroをプレイできますか？
はい、本作はSteam Deckで「プレイ可能」の評価を得ています。画面表示の滑らかさとバッテリー持続時間のバランスを最良にするには、クイックアクセス設定でリフレッシュレートを45Hzまたはフレームレートを60FPSに制限し、背面グリップのL4およびR4ボタンに武技の切り替えを割り当てるのがおすすめです。
