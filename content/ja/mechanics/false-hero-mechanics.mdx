## スーパーアーマーの仕組みと強靭度ブレイクシステム

本作のエネミーデザインの根幹にあるのが、アグレッシブなスーパーアーマーシステムです。下級の斥候から屈強な巨漢の重装兵に至るまで、ほぼすべての敵が生来のスーパーアーマーを備えています。弱攻撃を当てるだけで即座に怯む従来のハックアンドスラッシュとは異なり、本作の敵は近年のタクティカルなアクションRPGに近い挙動を示します。

このアーマーゲージの仕様を把握することは、序盤において最も重要な**『False Hero』のメカニクス**の一つです。敵を攻撃すると、不可視（または可視）の強靭度ゲージを徐々に削ることができます。しかし、回避や後退のために交戦を中断すると、このアーマーは瞬時に回復し始めるという点に注意が必要です。

```
プレイヤーの攻撃フェーズ -> アーマーゲージを削る -> ブレイク状態（スタン猶予） -> アーマーゲージ全快
```

敵のスーパーアーマーを完全に削り切ると、無防備な被弾スタン状態へと移行します。ただし、コミュニティの検証報告にもある通り、大型の敵はこのスタンからの復帰が極めて早く、わずか1〜2回通常斬撃を入れただけでスーパーアーマーが即座に復活することも珍しくありません。この一瞬のチャンスを最大限に活かすためには、威力の低い弱攻撃を連打するのではなく、瞬間火力の高いバーストスキルを叩き込む必要があります。

### アーマー状態と被弾リアクション

| 状態 | 敵の挙動 | 被ダメージ倍率 | 中断可能性 |
| :--- | :--- | :--- | :--- |
| **フル・スーパーアーマー** | 攻撃モーションを完遂；弱攻撃を無視 | 1.0倍（通常） | 不可（妨害不能） |
| **アーマー損耗** | 攻撃モーションを続行；非交戦1.5秒後に急速回復 | 1.0倍（通常） | 特殊戦技のみ中断可 |
| **強靭度ブレイク** | モーション強制キャンセル；一時的な体勢崩れ | 1.0倍～1.25倍 | 完全に中断可能 |
| **スタン復帰後** | 最初の反撃ヒット時に即座に強靭度全快 | 1.0倍（通常） | 不可（アーマー再展開） |

### 強靭度管理の実践的テクニック
* **削り80%で距離を取りすぎないこと：** 敵の広範囲薙ぎ払いを避けるためにローリングで離脱した場合でも、即座にダッシュ攻撃や遠距離投擲を繰り出し、アーマーの自動回復を阻止しましょう。
* **高威力スキルは最後のひと削りに温存する：** 通常の剣撃でゲージを削り、最後に戦技などの大技を叩き込んでブレイクを誘発することで、攻撃の勢いを維持したまま追撃チャンスへ移行できます。
* **複数戦での乱戦を避ける：** アーマー持ちの敵を同時に相手にするのは非常に危険です。1体を外側に誘い出し、ブレイクを狙うコンボの最中に画面外からの攻撃を受けないよう立ち回りましょう。

## エネルギーゲージとスキルローテーション：確定反撃の最大化

本作のキャラクターは、強力な戦技（Combat Arts）や防御アクションを繰り出すために専用のエネルギーゲージ（通称「紫ゲージ」）を使用します。このゲージの運用こそが、戦闘のテンポと快適性を大きく左右します。広範な**『False Hero』のメカニクス』**において、この紫のエネルギーゲージは攻撃テンポを司る最重要リソースとして機能します。

通常の剣攻撃は、主にエネルギーの生成とアーマー削りの手段として機能します。通常攻撃自体のダメージは控えめなため、主なダメージソースは戦技（Combat Arts）の連携によるバーストダメージとなります。エリート敵の強靭度を削るためだけにエネルギーを使い果たしてしまうと、いざ敵がスタンした決定的な瞬間にゲージが枯渇し、火力を出せなくなるリスクがあります。

### リソース消費と性能一覧

| アクション | エネルギー消費 | アーマー削り性能 | 硬直 / クールダウン |
| :--- | :--- | :--- | :--- |
| **弱斬撃（R1）** | 0（エネルギー生成） | 低 | 硬直なし（即時復帰） |
| **回転斬り戦技** | 35%消費 | 高（多段ヒット） | 中程度の後隙 |
| **強刺突戦技** | 50%消費 | 極めて高い | 長い復帰モーション |
| **防御パリィ** | 0（成功時にエネルギー還元） | 高（ノックバック） | 有効フレーム：約12〜16フレーム |

### 「回転斬り」バーストコンボループ
プレイヤーの検証により、攻撃範囲の広い戦技（回転斬りなど）は、適切な間合いを維持することで中堅エネミーや序盤ボスを圧倒できることが判明しています：

1. **中距離での攻撃誘導：** 敵の近接攻撃の最大射程外に立ち、後隙の大きな大振りの攻撃を空振りさせます。
2. **初撃戦技の発動：** 素早く踏み込み、メインの戦技を発動して残りのアーマーゲージを一気に削り落とします。
3. **二段目の追撃：** 敵に体勢を立て直させる恐れがある通常攻撃は挟まず、即座に2つ目のスキルへとキャンセル派生させ、スタン時間内に最大火力を叩き込みます。
4. **離脱＆チャージ：** 一歩引いて間合いを取り、安全な隙に単発の通常攻撃を当ててエネルギーを再充填し、このループを繰り返します。

## 防御システム：パリィ、回避、スタン復帰

的確な防御タイミングの習得もまた、がむしゃらなボタン連打と熟練の立ち回りを分ける重要な**『False Hero』のメカニクス**です。防御面では、ダイナミックな「回避ローリング」と精密な「パリィ」の2つの主要な選択肢が存在します。

本作のパリィシステムは、状況依存型という特徴を持っています。[False Hero Steam コミュニティハブ](https://steamcommunity.com/app/2538870/discussions/0/561408759868492651/)での報告や初期プレイヤーの検証によると、すべての攻撃をパリィできるわけではありません。予備動作が大きく分かりやすい特定の攻撃のみをカウンターできるように調整されています。これにより防御の自由度は制限されますが、パリィを成功させると敵の攻撃を完全に中断させて後方へ弾き飛ばし、スキルゲージを一定量回復させることができます。

### 防御メカニクスの比較

| 項目 | 回避 / ローリング | 精密パリィカウンター |
| :--- | :--- | :--- |
| **汎用性** | 通常攻撃および投擲・遠距離攻撃全般に対応 | カウンター可能に指定された特定攻撃のみ有効 |
| **リターン** | なし（スタミナや位置取りを消費） | エネルギーを生成し、敵の勢いを完全停止 |
| **リスク度** | 低〜中（敵の追尾攻撃に注意が必要） | 高（失敗時はカウンターダメージを直撃） |
| **集団戦制御** | 包囲網から安全に離脱 | 攻撃してきた対象を大きくノックバック |

### パリィのタイミングを極めるコツ
* **発光シグナルを見極める：** パリィを試みる前に、敵の特有のエフェクトや予備動作の構えを観察してください。通常のジャブや軽攻撃はパリィ入力を受け付けない仕様です。
* **ノックバックを計算に入れる：** 重量級の敵をパリィすると、数歩後ろへ大きく吹き飛ぶことがよくあります。スタンした敵に即座に追撃を入れるため、前ダッシュで間合いを詰める準備をしておきましょう。
* **リトライの移動ストレスを軽減する：** パリィをチュートリアルで学ぶエリアは、エレベーターやチェックポイントからの復帰路が長い場合があります。狭い通路でエリート敵に挑む前に、まずは周囲にいる孤立した雑魚敵でタイミングを練習するのが得策です。

## 育成メカニクス：戦技（Combat Arts）、知識（Knowledge）、素材

スキルの強化は、キャラクターの成長を支える根幹の**『False Hero』メカニクス』**と密接に結びついています。単一の通貨だけでレベルアップしていくシンプルなツリーとは異なり、『False Hero』では強化リソースが**「知識（Knowledge）」**（戦闘や探索を通じて蓄積される洞察）と**「強化素材（Upgrade Materials）」**（ワールド内を探索して拾い集める物理的アイテム）の2系統に分かれています。

この二重リソースシステムにより、計画的な育成が求められます。「知識」を大量に溜め込むだけでは剣技を強化することはできず、マップ探索で手に入る有限のクラフト素材を見つけ出し、投入する必要があります。

### 戦技（Combat Arts）強化チャート

| 強化段階 | 必要知識ポイント | 必要素材タイプ | 主な強化内容 |
| :--- | :--- | :--- | :--- |
| **Tier 1（基本）** | 0（初期解放） | なし | スキルの基本性能 |
| **Tier 2（強化）** | 100～250 Insight | 洗練の欠片（Refined Shards） | ダメージ+15%、後隙の軽減 |
| **Tier 3（上級）** | 400–600 Insight | 無垢の合金（Pristine Alloy） | 強靭度削り+25%、追撃判定の追加 |
| **Tier 4（極致）** | 1,000+ Insight | 古代のコア（Ancient Core） | 撃破時/スタン時にリソース還元 |

### ワールドの重大な分岐選択：蘇生か、処刑か
冒険の序盤、プレイヤーは倒した敵を「蘇生（Revive）」するか「処刑（Kill）」するかの重大な選択を迫られます。この決断はストーリーだけでなく、ゲームシステム上にも大きな影響を及ぼします：
* **処刑ルート（Kill）：** 敵を倒すことで即座に素材や攻撃系強化アイテムが手に入り、短期的にビルドを急激に強化できます。
* **慈悲ルート（Revive）：** 敵を蘇生させると、後々NPCとして再登場し、商人のラインナップ拡張や、ユニークなパッシブチャームの獲得につながることが多くなります。

## 探索・移動システムと環境トラップ

戦闘以外の場面で生き残るには、移動アクションとマップの構造を正しく把握することが不可欠です。本作のステージ探索における**『False Hero』の環境メカニクス**は、他の高難度アクションRPGとは一線を画す特徴を持っています。

まず、本作の落下ダメージは非常に寛容です。高台から躊躇なく飛び降りて地上の巡回兵を強襲したり、危険な階段トラップを丸ごとスキップしたりしても、体力を大幅に失うことはありません。この縦方向の自由度を活かし、常に高所を確保して落下攻撃を狙う立ち回りが推奨されます。

しかし、その自由度と引き換えに、背景に巧みに隠れた遠距離狙撃兵といった厄介な環境トラップが配置されています。画面外から飛来する遠距離弾は、足場移動を妨害するだけでなく、激しい近接戦の最中に被弾して体力を削られる大きな要因となります。

### 環境要素と戦術的対策

| トラップ / 環境要素 | 特徴・挙動 | 戦術的対策 |
| :--- | :--- | :--- |
| **画面外のスナイパー** | 高速の弾を発射；背景と同化している | 弾の軌跡を辿って射手を特定し、最優先で排除する |
| **落下ダメージ** | 通常の高さからの落下ペナルティが極めて軽微 | 高所からの跳躍で危険地帯をショートカット、または奇襲に利用 |
| **黄金のチュートリアル仮面** | アクションのお手本動画を表示するインタラクティブオブジェクト | 内蔵されたモーションを観察し、スキルのタイミングを学ぶ |
| **チェックポイントの祭壇** | 体力を全回復し、敵の配置をリセットする | ボス戦に挑む前に、リトライ時のルートを正確に把握しておく |

### ステージ攻略のベストプラクティス
1. **遠距離の敵を最優先で掃除する：** 弓兵や魔術師の射線が通っている状態で、アーマー持ちのエリート敵と交戦してはいけません。遠距離攻撃による怯みで、こちらの戦技モーションが中断されてしまいます。
2. **高低差を最大限に活用する：** 通路に複数の敵が密集している場合は上を見上げましょう。鉄骨、崩れた柱、突き出た足場などを経由することで、優先ターゲットの真上や背後に直接飛び降りることができます。
3. **素材を無駄遣いしない：** 序盤エリアで手に入る強化素材の数には限りがあります。手に入った戦技を片っ端から強化するのではなく、相性の良い2つのスキルに絞り、中盤までリソースを集中投資しましょう。

## 『False Hero』メカニクスに関するよくある質問（FAQ）

### 最優先でマスターすべき『False Hero』のメカニクスは何ですか？
最も重要なのは「敵のスーパーアーマー管理」です。通常攻撃ではエリート敵の行動を止められないため、通常斬撃を隙間に差し込んでエネルギーを蓄え、戦技で一気にアーマーを削り取ってから回避に移るという立ち回りが生存の鍵となります。

### ゲーム内のすべての攻撃をパリィできますか？
いいえ。パリィは予備動作が明瞭な特定の攻撃に対してのみ機能します。通常の素早い攻撃や遠距離からの投擲物は、ローリング回避や方向ジャンプで対処する必要があります。対象となる攻撃に対してパリィを成功させると、敵をノックバックさせ、貴重なエネルギーを回復できます。

### 戦技（Combat Arts）の強化に「知識」と「素材」の両方が必要なのはなぜですか？
これはキャラクター強化のバランスを保つための仕様です。「知識」は特定の敵との交戦から得られる戦闘経験値を示し、「物理的なクラフト素材」は、ワールドを十分に探索することなく序盤からスキルを過剰に強化してしまうのを防ぐストッパーとして機能しています。

### 『False Hero』の落下ダメージはどのように機能しますか？
一般的なソウルライク系ゲームと比較して、落下ダメージは極めて低く設定されています。かなりの高所から飛び降りても致命傷にはならないため、高低差の激しい立体的なエリアを探索する際は、縦方向の機動力を活かした移動や空中からの落下奇襲が非常に有効な戦術となります。
