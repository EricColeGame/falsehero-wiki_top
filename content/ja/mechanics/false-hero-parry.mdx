『False Hero』において、パリィの習得は過酷でハイスピードな戦闘を生き延びるために最も不可欠なスキルです。本作のようなシビアなダークファンタジーアクションでは、凶暴な異形の怪物や容赦ない機械の自動人形を相手に、パッシブな守りに徹していては生き残れません。パリィの仕組みを理解すれば、大振りの攻撃を仕掛けてきた敵に致命的なスタッガー（体勢崩し）の隙を作り出し、過酷なボス戦をリズミカルで爽快な勝利へと変えることができます。

体験版をプレイし始めたばかりの方でも、終盤の強敵に挑む熟練者であっても、防御のタイミングが戦況のすべてを左右します。盾に頼って引き籠もったり、回避ローリングを連打したりする従来のアクションRPGとは異なり、本作のバトルエンジンはその場に踏みとどまり、敵の攻撃を受け流すプレイヤーに報いる設計となっています。フレーム判定、予兆シグナル、そして追撃チャンスを正しく把握することで、あなたの立ち回りは「必死の生存」から「戦場の完全掌握」へと進化するはずです。

## False Heroのパリィを理解する：基本メカニクスと操作

本作の戦闘システムは、素早いステップ回避と精密な弾き（デフレクト）がシームレスに融合した、極めて流動的な防御アクションを基本としています。パリィを安定して成功させるには、敵の武器や四肢が振り下ろされる直前、スイングが最頂点から前方に加速した瞬間に防御ボタンを入力する必要があります。単に衝撃を受け流すだけでなく、パリィを成功させることで敵の勢いを中断させ、即座に手痛い反撃を叩き込む絶好の隙を作り出せます。

先行テストを体験したコミュニティからの報告によると、本作の最も優れた設計の一つは、防御アクションから攻撃コンボへの移行がいかに滑らかであるかという点です。完璧なタイミングで攻撃を弾くことができれば、ダメージを完全に無効化するだけでなく、スタミナ消費を抑え、即座に攻勢へと転じる起点を作り出すことができます。

```
[敵の攻撃の溜め・予兆] ➔ [インパクトの瞬間に防御入力] ➔ [弾き発生] ➔ [体勢崩し / 反撃チャンス]
```

弾き、ローリング回避、あるいは間合いを取るべきかを瞬時に判断するためには、各選択肢が位置取りやリソースにどのような影響を与えるかを理解しておく必要があります。

| 防御アクション | 消費リソース | リスク | 主なメリット | 追撃のチャンス |
| :--- | :--- | :--- | :--- | :--- |
| **パリィ / 弾き** | スタミナ小 | 高 | スタッガー値の蓄積最大、姿勢ダメージ無効化 | 即座のクリティカル攻撃やコンバットアーツの発動 |
| **回避ローリング** | スタミナ中 | 低〜中 | 完全な位置の再調整、無敵フレームの獲得 | 敵の背後への回り込み、広範囲な薙ぎ払いの離脱 |
| **間合い調整 / バックステップ** | スタミナなし | 中 | 戦闘のテンポをニュートラルに維持、連撃トラップの回避 | 安全な遠距離スキルの使用、フォーカスの回復 |

開発フォーラムに寄せられたプレイヤーの感想では、防御アクションの操作性は非常にタイトでレスポンスが良いと高く評価されています。しかし、防御ボタンをパニック時の連打用ボタンとして扱えば、瞬く間に叩き潰されることになります。タイミングを外せば大ダメージを受け、重い被弾硬直が発生するため、意識的な練習が欠かせません。

## 受付フレーム、タイミング、敵の予備動作の見極め方

多彩な敵を相手にパリィを確実に決めるには、敵のアニメーションの初動を見極める観察眼が不可欠です。このジャンルの高難度アクションにおいて、敵の攻撃は一般的に「予兆（溜め）」、「発生（実際の振り）」、「硬直（フォロースルー）」という3つの段階で構成されます。

弾きの判定ウィンドウが有効になるのは、発生フェーズの極めて初期のフレームです。溜め動作の段階で防御ボタンを押してしまうと、弾きの判定が空振りし、壊滅的なダメージをまともに受けてしまいます。

*   **初動 / 予兆：** 敵が腕を引く、体をひねる、あるいは武器を振り上げる段階。ここでは絶対にパリィを入力してはいけません。
*   **攻撃の発生：** 武器があなたの当たり判定に向かって急加速する段階。攻撃が手元へ振り下ろされ始めた瞬間に、防御入力を合わせます。
*   **音と視覚のエフェクト：** 一部の強力な攻撃やガード不可攻撃では、固有の光条や機械的な予兆音が鳴ります。通常の攻撃でも微かに光るため、それがパリィ推奨タイミングの合図となります。

| 攻撃カテゴリー | パリィの有効性 | 理想的な反応ポイント | 失敗時のリスク |
| :--- | :--- | :--- | :--- |
| **通常の弱攻撃** | 高 | 武器が前方に振り下ろされ始めた瞬間 | わずかな姿勢低下、削りダメージ |
| **大振りの叩きつけ** | 中 | 地面へ叩きつけられる直前の最高到達点からの落下時 | 大きなダウン、深刻な体力消費 |
| **赤く光る突進 / ガード不可** | なし（回避必須） | 赤い発光エフェクトが発生した瞬間 | 体力の大半を喪失、ガードクラッシュ |
| **多段連続攻撃** | 高（連続弾き） | 各攻撃のヒットごとにリズミカルに入力 | スタッガー状態に持ち込まれ、フルコンボ被弾 |
| **遠距離の射出物** | 低〜中 | 弾がプレイヤーのモデルに接触する直前 | 弾き失敗、プレイヤー側が体勢を崩す |

極限の精度が要求されるタイトルと比較すると、本作のデフォルトのパリィ受付フレームは比較的寛容であるとプレイヤーコミュニティからは評されています。しかし、テンポの速い多段攻撃に対しては、正確でリズミカルな入力が求められます。これらの視覚的サインを把握することで、どの攻撃を受け流すべきか、あるいは回避ローリングに切り替えるべきかを正確に判断できるようになります。

## パリィを攻撃へ昇華：スタッガー、体勢、コンバットアーツ

弾きとは、本質的に「防御の仮面を被った攻撃ツール」です。パリィを綺麗に決めるたびに、相手の目に見える（あるいは不可視の）体勢ゲージ（ポイズ）へ大きなダメージを与えることができます。

開発元は[False Hero Steamコミュニティの掲示板](https://steamcommunity.com/app/2538870/discussions/0/800091752203644579/)にて、想定されたバトルのリズムを明確に明かしています。敵の体勢が崩れてスタッガー状態に陥ったら、プレイヤーは素早いコンボでアグレッシブに攻め立て、怯み状態を維持し続けなければなりません。スタッガーゲージは一瞬で消滅するわけではないため、高威力のコンバットアーツや武器コンボを叩き込む十分な猶予が与えられています。

| パリィ成功後のアクション | スタッガーへの寄与 | フォーカス / マナ効率 | 最適な戦術的シチュエーション |
| :--- | :--- | :--- | :--- |
| **通常弱攻撃コンボ** | 中 | 高（フォーカスを蓄積） | 敵の怯み時間の延長 |
| **溜め強攻撃（突きなど）** | 高 | ニュートラル | 残りの体勢閾値を完全に破壊する |
| **装備中のコンバットアーツ** | 極大 | フォーカスを消費 | 完全にスタッガーしたボスへの特大ダメージ |
| **素早い回り込みステップ** | 低 | 低 | 背後致命（クリティカル）を狙う立ち回り |

敵のスタッガーゲージが限界に達すると、無防備な崩れモーションに移行します。ここで息を整えるために距離を取るのではなく、一気に間合いを詰めましょう。弱攻撃の連打から最大の威力を誇るコンバットアーツへと繋げることで、敵が体勢を立て直す前に最大のダメージを奪い取ることができます。

```
[パリィ成功] ➔ [体勢ゲージ削り] ➔ [スタッガー発生] ➔ [弱攻撃の連撃] ➔ [コンバットアーツのフィニッシャー]
```

## ボス戦攻略：主要な戦闘における立ち回り

ボス戦は、プレイヤーの防御タイミングの精度を測る究極の試練です。有機的な触手の薙ぎ払いから機械仕掛けの突進攻撃まで、ボスごとに固有の攻撃リズムが存在します。ボス戦でパリィを戦略的に使いこなせるかどうかが、勝利と敗北の分かれ目となります。

### 1. イグノランス（Ignorance）
イグノランスは、プレイヤーの早とちりしたパリィ入力を誘うような、独特で極端に溜めの長い大振り攻撃を繰り出してくることで知られています。薙ぎ払いの発生が意図的に遅らされているため、焦ってボタンを押すと無防備な状態で直撃を受けます。
*   **戦術：** 巨大な腕が完全に前へと振り出される瞬間まで、入力をぐっと我慢しましょう。腕が振り下ろされる直前に低い唸り声を上げることが多いため、音声の手がかりも有効です。
*   **スタッガーの狙い目：** 頭上からの叩きつけ攻撃をパリィすることで体勢を大きく崩し、フルコンボを叩き込む絶好のチャンスが生まれます。

### 2. 改良型防衛ユニット（Advanced Protection Unit / 装甲ロボット）
改良型防衛ユニット戦では、通常の近接攻撃とガード不能の強力な技を瞬時に見分ける判断力が試されます。
*   **戦術：** 通常の剣による斬撃やロボットアームの振り払いは積極的に弾きましょう。ただし、コミュニティでも注意喚起されている特徴的な「赤く光る突進攻撃」には細心の警戒が必要です。赤く発光する攻撃はパリィ不可のため、横ステップやローリングで必ず回避してください。
*   **スタッガーの狙い目：** 剣による3連撃の最終段を弾くと、ロボットが数秒間完全に機能停止し、無防備になります。

### 3. 触手の異形（The Tentacle Abomination）
第2フェーズに入ると、予測しづらい当たり判定と目まぐるしい触手の乱舞が襲いかかります。
*   **戦術：** 本体の中心部に近い位置をキープしてください。触手の水平薙ぎ払いは、先端付近よりも根本〜近距離のほうが弾きやすく、スピードのブレや判定のムラに惑わされにくくなります。
*   **スタッガーの狙い目：** 2本の触手による同時の叩きつけに対して連続でパリィを成功させると、即座にスタッガー状態へ追い込むことができます。

| ボス | 主な攻撃速度 | 最も警戒すべき脅威 | 推奨カウンター戦術 |
| :--- | :--- | :--- | :--- |
| **イグノランス** | 低速（ディレイ大） | ディレイの効いた頭上叩きつけ | 防御入力を遅らせる。振り下ろしの初動を注視 |
| **防衛ユニット** | 中速（リズミカル） | 赤い突進（ガード不可） | 3連撃はパリィ、赤く光る突進はローリング回避 |
| **触手の異形** | 高速（不規則） | 広範囲の薙ぎ払い攻撃 | 本体に密着し、攻撃の飛翔時間を抑えて対処 |
| **病み患いの類人猿** | 高速（アグレッシブ） | 跳躍からの叩きつけ＆岩投げ | 近接の引っかきはパリィ、投擲岩は前転で回避 |

## 上級テクニック、ビルドのシナジー、よくある失敗

パリィの成功率を極限まで高めるには、操作設定の見直し、リソース管理、そして戦況把握を最適化する必要があります。マッスルメモリー（筋肉記憶）の定着には時間がかかりますが、典型的なソウルライク的ミスを避けることで、上達のスピードを飛躍的に早めることができます。

### 操作系とキーバインドの最適化
マウス＆キーボードでプレイする場合は、コンバットアーツと弾きの入力を移動キーのすぐ近くに割り当てることがコミュニティで強く推奨されています。防御入力までの指の移動距離を最小限に抑えることで、反応速度が劇的に向上します。コントローラーでプレイする場合も同様に、パリィと通常攻撃のボタンをスムーズに行き来できる配置にし、守りから攻めへと淀みなく切り替えられるように設定しましょう。

### 弾きにおいて陥りがちなミス
他のアクションゲームの癖をそのまま持ち込んでしまうと、本作のシステムでは手痛いしっぺ返しを食らいます。プレイヤーからのフィードバックで特に多く見られるミスは以下の通りです：

*   **パリィボタンの連打（ガチャ押し）：** パリィを連打すると有効フレームが急激に縮小し、弾き判定が消失して大ダメージを受けます。
*   **スタッガー時の追撃不足：** 敵が体勢を崩した際、スタミナ回復のために距離を取ってしまうと、スタッガー時間を無駄にしてしまいます。迷わず攻勢をかけましょう。
*   **赤攻撃を弾こうとする：** 危険なガード不可攻撃は赤く発光します。この視覚的警告を軽視せず、確実にローリングで離脱してください。
*   **フォーカスゲージの放置：** コンバットアーツは膨大な体勢ダメージを与えますが、発動にはフォーカスが必要です。パリィの合間に通常攻撃を挟み、リソースを常に確保しておきましょう。

| よくあるミス | 戦闘中に起きる事象 | 改善策 |
| :--- | :--- | :--- |
| **パリィの連打** | 受付判定が消失し、攻撃を直撃で受ける | 武器が前方に振り下ろされる瞬間まで引きつけて1回押す |
| **スタッガー時の躊躇** | ダメージを与えられないまま敵が体勢を回復する | 即座に弱攻撃コンボと強力なコンバットアーツを叩き込む |
| **ディレイ攻撃の見誤り** | 溜めモーション中にパリィを押してカウンターを食らう | 武器の先端ではなく、敵の肘や肩の動きに注目する |
| **スタミナの枯渇** | 体勢を崩され、無防備な状態に陥る | パリィの合間に微小な後退を挟み、スタミナ回復を促す |

## False Heroのパリィに関するよくある質問（FAQ）

### 他のソウルライクゲームと比べてパリィの受付時間は寛容ですか？
体験版をプレイしたユーザーの声によると、本作の弾き判定は『SEKIRO』などの極めてシビアな作品と比較するとやや広めに設定されており、ミクロ単位の超人的な反応がなくても十分に合わせられる設計です。ただし、ボスのディレイ攻撃や目まぐるしい連撃に対しては、当てずっぽうの連打ではなく的確なタイミング入力が求められます。

### すべてのボスの攻撃をパリィで弾くことはできますか？
いいえ。通常の武器攻撃、薙ぎ払い、物理的な叩きつけはパリィ可能ですが、改良型防衛ユニットの赤く光る突進など、特定の強攻撃は完全なガード不能技となっています。こうした赤く光る攻撃は、ローリング回避やダッシュでの位置取りでやり過ごす必要があります。

### パリィはスタッガーゲージにどのように影響しますか？
敵の攻撃を弾くと、相手のポイズ（体勢）ゲージに直接大きなダメージを与えます。このゲージが最大まで蓄積されると、敵はスタッガー状態に陥ります。一般的なソウル系ゲームのように固定モーションの致命の一撃（内臓攻撃）を1回決めて終わる仕様とは異なり、本作ではスタッガー中の敵を激しく攻撃し続けることで怯み状態を延長させ、大ダメージの連携を叩き込むことができます。

### 序盤はパリィと回避ローリングのどちらを優先すべきですか？
バランス良く使い分けるのが理想ですが、序盤のうちからパリィの感覚を掴んでおくことは後々大きなアドバンテージになります。通常モブの攻撃や挙動が分かりやすいボスの振りは、パリィで弾いてスタッガーを奪いスタミナを温存するのが最も効率的です。一方で、広範囲に及ぶ薙ぎ払いやガード不可の突進に対しては、迷わず回避ローリングを選択しましょう。
